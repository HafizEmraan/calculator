Determining the Upgrade Path

This explains the steps to follow to determine the path you need to take to update your version of the product.

This section explains the principles to follow to determine whether you can perform the update directly or must update first to a Full Release version.

Full Release as target

Upgrade directly. A Full Release contains every release before it.

Regular Release as target

If a Full Release lies in between, install the latest one first, then the target.

Several Full Releases in between

Skip the older ones. Only the latest Full Release before the target is needed.
